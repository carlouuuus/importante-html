JavaScript

JavaScript es un lenguaje de programación utilizado para agregar interactividad y comportamiento a las páginas web. En Pingui Store puede utilizarse para botones, menús, carritos, efectos y acciones interactivas.

HTML

Representa la estructura del sitio web.

CSS

Define los colores, tamaños, fuentes y apariencia.

JavaScript

Permite agregar comportamiento e interacción.

Conceptos básicos

Variables: almacenan datos como nombres o precios.

Funciones: contienen instrucciones que pueden ejecutarse.

Eventos: responden a acciones como hacer clic.

Ejemplo

let producto = "Peluche Pingüino";

function mostrarProducto() {
    alert("Has seleccionado: " + producto);
}

jQuery

jQuery es una biblioteca de JavaScript creada para simplificar tareas frecuentes del desarrollo web, como seleccionar elementos, modificar contenido y crear efectos.

Sintaxis

$("#producto")
$("#menu").slideToggle()

✓ Ventajas

Su sintaxis es sencilla y facilita efectos y animaciones.

✗ Desventajas

JavaScript moderno puede realizar muchas de estas tareas sin depender de una biblioteca.

JSON

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transmitir datos entre aplicaciones y servidores.

Objeto JavaScript

const producto = {
  nombre: "Peluche Pingüino",
  precio: 15.99
};

Cadena JSON

{
  "nombre": "Peluche Pingüino",
  "precio": 15.99,
  "categoria": "Peluches",
  "disponible": true
}

Una tienda como Pingui Store podría utilizar JSON para recibir información sobre nombres, precios y disponibilidad de productos desde un servidor o API.

Web Hosting y Dominios

El hosting permite almacenar los archivos de un sitio web en servidores conectados a Internet.

Compartido

Varios sitios comparten los recursos de un servidor.

VPS

Ofrece recursos virtuales más independientes.

Nube

Utiliza diferentes servidores conectados.

Dominios

Un dominio es el nombre utilizado para acceder a un sitio web. Ejemplo: pinguistore.com.

Un TLD es la terminación como .com, .net u .org.

Un subdominio puede ser tienda.pinguistore.com.
