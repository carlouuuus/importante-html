JavaScript (JS Vanilla) 💻

JavaScript es un lenguaje de programación utilizado para agregar interactividad y comportamiento a las páginas web. En Pingui Store permite crear botones, menús, efectos y acciones interactivas.

HTML, CSS y JavaScript

HTML

Proporciona la estructura de la página web.

CSS

Controla los colores, tamaños, fuentes y diseño.

JavaScript

Agrega comportamiento e interacción.

Conceptos básicos

Variables: almacenan información como el nombre o precio de un producto.

Funciones: contienen instrucciones que pueden ejecutarse cuando sea necesario.

Eventos: permiten responder a acciones del usuario, como hacer clic en un botón.

Ejemplo práctico

let producto = "Peluche Pingüino";

function mostrarProducto() {
    alert("Has seleccionado: " + producto);
}

jQuery 💙

jQuery es una biblioteca de JavaScript creada para simplificar la programación de páginas web. Facilita tareas como seleccionar elementos, modificar contenido y crear animaciones.

Sintaxis básica

$("#producto")

El símbolo $ se utiliza para seleccionar elementos y trabajar con ellos de una manera sencilla.

Ventajas y desventajas

✓ Ventajas

Su sintaxis es sencilla y facilita la creación de efectos y animaciones.

✗ Desventajas

Actualmente muchas funciones pueden realizarse directamente con JavaScript moderno.

Efectos típicos

$("#producto").fadeIn();
$("#menu").slideToggle();

JSON 🗂️

JSON significa JavaScript Object Notation. Es un formato utilizado para almacenar y transmitir información entre aplicaciones y servidores.

Estructura básica

JSON utiliza pares de clave y valor, objetos y arreglos para organizar los datos.

{
  "nombre": "Peluche Pingüino",
  "precio": 15.99,
  "categoria": "Peluches",
  "disponible": true
}

Objeto JavaScript

const producto = {
  nombre: "Peluche Pingüino",
  precio: 15.99
};

Cadena JSON

'{"nombre":"Peluche Pingüino","precio":15.99}'

Uso en aplicaciones web

Las aplicaciones web utilizan JSON para enviar y recibir información de servidores o APIs. Por ejemplo, Pingui Store podría recibir mediante JSON los nombres, precios y disponibilidad de sus productos.

Web Hosting y Dominios 🌐

Para que Pingui Store pueda estar disponible en Internet, sus archivos deben almacenarse en un servidor mediante un servicio de hosting.

¿Qué es Web Hosting?

El web hosting es un servicio que permite almacenar los archivos de un sitio web en un servidor conectado a Internet.

Tipos de Hosting

Compartido

Varios sitios utilizan los recursos de un mismo servidor.

VPS

Proporciona recursos más independientes dentro de un servidor.

Nube

Utiliza diferentes servidores conectados para ofrecer flexibilidad.

Vercel

Vercel es una plataforma que permite publicar sitios web, especialmente proyectos estáticos y aplicaciones modernas. Pingui Store puede colocar sus archivos HTML, CSS y JavaScript en Vercel para hacerlos accesibles desde Internet.

¿Qué es un dominio?

Un dominio es el nombre que las personas utilizan para acceder a un sitio web, por ejemplo: pinguistore.com.

TLD

El TLD es la terminación de un dominio. Algunos ejemplos son .com, .net y .org.

Subdominio

Un subdominio es una sección independiente dentro de un dominio, por ejemplo: tienda.pinguistore.com.

Propagación DNS

🐧Usuario
🌐Dominio
🔎DNS
🖥️Hosting
🛍️Pingui Store

La propagación DNS es el proceso mediante el cual los cambios realizados en los registros DNS se actualizan y son reconocidos por diferentes servidores de Internet.
