JavaScript

JavaScript es un lenguaje de programación utilizado para agregar interactividad y comportamiento a las páginas web. En Pingui Store puede utilizarse para botones, menús, carritos, efectos y acciones interactivas.

HTML

Representa la estructura del sitio web.

CSS

Define los colores, tamaños, fuentes y apariencia.

JavaScript

Permite agregar comportamiento e interacción.

Conceptos básicos

Variables: almacenan datos como nombres o precios.

Funciones: contienen instrucciones que pueden ejecutarse.

Eventos: responden a acciones como hacer clic.

Ejemplo

let producto = "Peluche Pingüino";

function mostrarProducto() {
    alert("Has seleccionado: " + producto);
}
