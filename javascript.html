JavaScript (JS Vanilla)

JavaScript es un lenguaje de programación utilizado para agregar interactividad y comportamiento a las páginas web. En Pingui Store permite crear funciones como botones, menús, efectos y acciones interactivas.

HTML, CSS y JavaScript

  • HTML: proporciona la estructura de la página.
  • CSS: controla los colores, tamaños, fuentes y diseño.
  • JavaScript: agrega comportamiento e interacción.

Conceptos básicos

Variables: almacenan información, como el nombre o precio de un producto.

Funciones: contienen instrucciones que pueden ejecutarse cuando sea necesario.

Eventos: permiten responder a acciones del usuario, como hacer clic sobre un botón.

Ejemplo práctico

let producto = "Peluche Pingüino";

function mostrarProducto() {
    alert("Has seleccionado: " + producto);
}
