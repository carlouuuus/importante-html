jQuery

jQuery es una biblioteca de JavaScript creada para simplificar tareas frecuentes del desarrollo web, como seleccionar elementos, modificar contenido y crear efectos.

Sintaxis

$("#producto")
$("#menu").slideToggle()

✓ Ventajas

Su sintaxis es sencilla y facilita efectos y animaciones.

✗ Desventajas

JavaScript moderno puede realizar muchas de estas tareas sin depender de una biblioteca.
