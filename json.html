JSON

JSON (JavaScript Object Notation) es un formato ligero para almacenar e intercambiar datos. Organiza la información mediante pares de claves y valores, y también permite agrupar varios elementos en listas.

¿Para qué sirve?

Almacenar

Permite organizar información de productos, precios y categorías.

Intercambiar

Facilita el envío de datos entre aplicaciones y servidores.

Organizar

Utiliza una estructura clara y fácil de leer.

Ejemplo de JSON

Este ejemplo representa un producto de Pingui Store con su nombre, precio y disponibilidad.

{
  "nombre": "Peluche Pingüino",
  "precio": 12.99,
  "disponible": true
}
